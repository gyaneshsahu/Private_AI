How did my savings grow from 2022 to 2026, and how do I work out the yearly rate?

Your savings grew from €4,200 to €9,850, which is about 23.7% a year on average.

How the yearly rate is worked out

Divide the end value by the start value, take the root for the number of years, and subtract one. In a spreadsheet that is =(B2/B1)^(1/4)-1. The same in Python:

python
def yearly_rate(start, end, years):
    # compound annual growth rate
    return (end / start) ** (1 / years) - 1

yearly_rate(4200, 9850, 4)   # 0.2375
