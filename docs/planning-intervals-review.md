## Disposition

The observed arithmetic/interval allocation improved across both tasks, while
semantic compliance and concision did not reliably follow the instructions.
Keep the targeted policy as partial improvement, with failures visible. G2 remains
IN PROGRESS, not qualified. Do not run the same probes again without a new approach.

The next useful planning experiment should test a genuinely different response
contract or provider capability, with exact constraint checks and broader transfer
cases. Do not silently rewrite model answers or label heuristic checks as verified
reasoning. Deterministic tools must be explicitly represented as tools if added;
the current model has none. Human review still assesses whether activities are
realistic, useful and consistent with the user's intent.
