# Copy audit: user-visible claims against the facts — 12 November 2026

**Fixed the same night (agent, not owner text):** #3 photo note, #4 export note, #5 and #6 stale search wording, #8 banner ("verified" removed; all-pass now says every review check passed), #10 billing claim removed (reply-stream, fallback prompt, code comment), #15 and #16 status and refusal wording, #22 banner line. Guarded by `tests/copy-overclaims.test.ts`. **Left for the owner:** #1, #2 (live policy text), #7 (owner wording of the arithmetic note), #9 (static "chat unavailable" lines: correct while chat is off; change when switching chat on, with D7), #11, #12 (drafts D2, D8), and every row of Table 2 (approved statement). Low rows #13, #14, #17 to #21 not changed.

Read-only audit. No source file was changed. Scope: `src/**/*.tsx`, user-shown string literals in `src/**/*.ts`, `shared/*.ts` copy, server pages, emails and browser-facing errors in `server/*.ts`, `index.html`.

Facts used as the bar: browser check of the secure server is PARTIAL (repository, release digest, key binding only; no freshness, revocation or TDX check in the browser; GPU/worker chain not proven). Tinfoil short-term prompt cache: no user control, no promised maximum ("usually within minutes, sometimes hours"). Metadata (time, model, token counts) kept 90 days. Identifier masking is pattern-based and incomplete (German held-out recall 97.8%, scans 87.3%); health details are never masked. Arithmetic gate FAILED; the app only recomputes arithmetic a reply writes out (`src/arithmetic/postcheck.ts:1-10`). Provider claims must match `docs/provider-promises-20261112.md`.

Severity: high = false or misleading promise; medium = could mislead; low = wording.

## Checked and found supported

- Cache wording, "no promised maximum", 90-day metadata and "does not use them to train": `shared/privacy-copy.ts:33` matches the promises map for Tinfoil.
- "your own address is not sent" (`shared/privacy-copy.ts:43`): `server/research.ts:183-186` sends only `Accept` and a generic `User-Agent`.
- "We do not retain device fingerprints or location" (`src/AccountAccess.tsx:127-128`): sessions store `ipAddress: null, userAgent: null` (`server/account-auth.ts:195`, `207`).
- Before each request, the browser check runs again (`src/verified-chat.ts:327`, `414`).
- Answer note on masking (`src/App.tsx:1657-1661`), calculator footers (`src/calculator-turn.ts:343`, `src/checked-response.ts:271`, `src/scoped-research.ts:188`) and the delete-everything panel (`src/App.tsx:2692-2700`) say exactly what the code does.
- `index.html` (title "Personal help, thoughtful privacy"), the access page and the security-notice emails make no overclaims.
- No "GDPR compliant", "end-to-end", "anonymous" (except "no anonymous mode") or "guarantee" promises in user-visible text.

Not checked: whether the 90-day purge runs on a schedule in production; how a proposed search query is built from the conversation (`src/App.tsx:2359` "never automatically added" was not traced); text inside `public/vendor`.
