# German interface glossary (13 November 2026)

Use these terms in every German string so the interface reads as one product. Address the user with **Sie** (formal) everywhere, including buttons ("Senden", "Speichern") and messages ("Bitte versuchen Sie es in einer Minute erneut."). Plain, short sentences; no anglicisms where a common German word exists. Keep CometRow, Privatemode, Tinfoil, Brave, Google as names.
